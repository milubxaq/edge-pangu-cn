# 中文排版助手（Edge 扩展）

在网页编辑器里一键整理选中文字的中文排版。

## 功能

- **右键菜单**：选中文字 → 「中文排版：整理选中文字」
- **快捷键**：`Alt+Shift+P`
- **工具栏弹窗**：勾选是否补空格/标点转换，点击按钮处理当前选区
- 可编辑区域（文本框、contenteditable 编辑器）直接替换原文；普通网页文字则复制整理结果到剪贴板并提示
- 跳过代码块、行内代码、URL、链接地址

## 适用场景

- 在网页版公众号、知乎、Notion、飞书文档里写中文
- 从网页复制段落进笔记前的快速整理

## 本地安装（未上架前）

1. 打开 `edge://extensions`
2. 开启「开发人员模式」
3. 点击「加载解压缩的扩展」，选择本目录

## 隐私

扩展不联网、不上传任何内容，设置仅保存在浏览器本地同步存储。
